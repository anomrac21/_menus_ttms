POS / Loyverse

Connect Loyverse OAuth. Menu catalog stays in Hugo/CMS; map variant IDs on items or in data/pos-mapping.yaml.

Connection

Checking…

Copy the store id into hugo.toml params.posintegration.store_id (or leave blank to use the first store).

Mapping

Set loyverse_variant_id on each price row (or item), or fill data/pos-mapping.yaml keys like Item Title|Size. Use Load Loyverse items after connect to copy UUIDs.
